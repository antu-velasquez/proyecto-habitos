# Aplicación de Gestión de Hábitos - Semana 1

Este proyecto es una herramienta para ayudar a las personas a crear y controlar sus hábitos basándose en el libro "Hábitos Atómicos".

## Requisitos
- Node.js instalado.
- Base de datos en MongoDB Atlas.

## Configuración Inicial
1. Clonar el repositorio y situarse en la rama `semanal`.
2. Ejecutar el comando `npm install` para instalar las dependencias (Express, Mongoose, etc.).
3. Crear un archivo `.env` en la raíz y configurar la variable `MONGO_URI` con el enlace de MongoDB Atlas.

## Ejecución
Para iniciar el servidor, utilizar el comando:
`node index.js`.
